while문이란?

while문은 조건식이 참인 동안 중괄호 블록 안의 실행문을 계속 반복하는 반복문이다.

몇 번 반복할지 정확히 알고 있을 때는 for문이 편하지만, “조건이 만족되는 동안 계속”이라는 상황에는 while문이 자연스럽다. 플레이어의 HP가 0이 될 때까지 공격하거나, 입력이 올바를 때까지 다시 입력받는 경우가 대표적이다.

조건식while (조건)
➜
실행 블록조건이 참이면 반복
➜
값 변경다시 조건을 확인
한 줄 정리 👉 while문은 “조건이 아직 참인가?”를 매번 확인하면서, 참인 동안 같은 코드를 반복한다.
SYNTAX

기본 문법과 실행 순서

while (조건식)
{
    반복 실행할 문장;
    반복 실행할 문장;
}
1
조건 확인

조건식이 참인지 먼저 검사한다.

2
블록 실행

참이면 중괄호 안의 코드를 실행한다.

3
다시 검사

실행이 끝나면 조건으로 돌아간다.

4
반복 종료

조건이 거짓이 되는 순간 빠져나온다.

여백 메모 ✏️ while문은 블록을 실행하기 전에 조건을 확인한다. 처음부터 조건이 거짓이면 실행문을 한 번도 실행하지 않고 바로 종료한다.
COUNTER LAB

반복을 멈추려면 값이 변해야 한다

가장 흔한 종료 방식은 반복할수록 조건이 거짓이 되도록 값을 바꾸는 것이다. count가 1에서 시작해 6이 되면 count <= 5가 거짓이 된다.

int count = 1;

while (count <= 5)
{
    printf("%d번째!\n", count);
    count = count + 1; // 조건을 거짓으로 만드는 값 변경
}

🔢 COUNT / WHILE LAB

count <= 5 인 동안 반복
CURRENT COUNT 1

count <= 5 → true · 반복 실행 가능

count를 1부터 5까지 올려보세요.

STOP

while문을 멈추는 두 가지 방법

METHOD 01

조건이 거짓이 되게 하기

count++, hp -= 10처럼 반복할 때마다 값을 바꿔 언젠가 조건이 거짓이 되도록 만든다. 가장 일반적인 방법이다.

METHOD 02

break로 강제 탈출

조건이 항상 참인 무한 루프 안에서도 특정 순간 break를 만나면 즉시 반복문을 빠져나온다.

while (1) // 조건이 항상 참인 무한 루프
{
    if (count == 5)
    {
        break; // 여기서 강제로 탈출
    }

    count++;
}
⚠️ 값 변경 코드를 깜빡하면?

조건이 영원히 참으로 남아서 무한 루프에 빠질 수 있다. 아래처럼 흐름이 계속 맴도는 상태가 된다.

1234∞
while (count <= 5) { /* count를 바꾸지 않음 */ }
GAME LOGIC

몬스터 처치 예제

게임에서 몬스터의 HP가 0보다 큰 동안 공격한다고 생각해보자. 공격할 때마다 HP를 10씩 줄이면, HP가 0이 되는 순간 while문이 끝나고 처치 메시지가 출력된다.

#include <stdio.h>

int main(void)
{
    int monster_hp = 100;

    while (monster_hp > 0)
    {
        monster_hp -= 10;
        printf("공격! 몬스터 체력: %d\n", monster_hp);
    }

    printf("몬스터를 처치했다!\n");
    return 0;
}

⚔️ MONSTER HP / WHILE BATTLE

HP > 0 인 동안 공격
👾
몬스터 HP: 100
100 / 100

while (monster_hp > 0) → 전투를 시작하세요.

헷갈렸던 부분 ✏️ while (monster_hp > 0)은 “HP가 0보다 큰 동안 반복”이라는 뜻이다. HP가 0 이하가 되어야 멈추므로, 그 전까지는 조건이 참이어야 한다. 반대로 while (monster_hp <= 0)으로 쓰면 처음부터 조건이 거짓이라 공격 코드가 실행되지 않는다.
WATCH OUT

while문에서 자주 하는 실수

❌ 조건을 반대로 작성

while (monster_hp <= 0)
{
    monster_hp -= 10;
}

처음 HP가 100이면 조건이 거짓이라 한 번도 실행되지 않는다.

✅ 반복되는 동안 값 변경

while (monster_hp > 0)
{
    monster_hp -= 10;
}

HP가 점점 줄어들어 조건이 거짓이 되고 안전하게 끝난다.

디버깅 질문 👉 “이 반복문 안에서 조건에 영향을 주는 값이 실제로 바뀌고 있는가?”를 먼저 확인하면 무한 루프를 빠르게 찾을 수 있다.
CHECKPOINT

🔁 스테이지 클리어 조건

  • while (조건식)은 조건이 참인 동안 블록을 반복 실행한다.
  • 반복문 안에서 조건에 영향을 주는 값을 바꿔야 종료할 수 있다.
  • 조건이 처음부터 거짓이면 블록은 한 번도 실행되지 않는다.
  • break는 반복 중인 while문을 즉시 탈출한다.
  • 조건을 바꾸지 않으면 무한 루프에 빠질 수 있다.
